# QA Tool

Минимальный персональный QA-инструмент на React, Vite, TypeScript и shadcn/ui (Radix).

Левое меню переключает разделы и проекты. В верхней строке отображается текущий
пользователь и доступна кнопка выхода. Регистрация и вход работают в демо-режиме:
аккаунты и текущая сессия хранятся только в React state и сбрасываются после
перезагрузки страницы.

В меню проекта доступны «Добавить проект» и «Удалить текущий проект».
Новый проект доступен обоим пользователям и содержит пустой Smoke.
Удаление требует подтверждения и удаляет также все данные и черновики проекта.
После удаления последнего проекта можно создать новый через то же меню.

Voicli содержит стартовый Smoke, QP Notes изначально пуст. Тесты, пункты
подготовки и результаты имеют `projectId`; данные и черновики хранятся отдельно
для каждого проекта и сохраняются при переходах в пределах текущей сессии.
Audit, Requirements, Test Plan, Checklists и Test Cases — страницы-заглушки.

```sh
npm install
npm run dev
```

Экран Smoke содержит 16 стартовых тестов, редактируемый checklist подготовки,
инструкции в раскрывающихся строках и отдельную рабочую панель с историей результатов.
Подготовка изначально пустая; инструкции и ожидаемые результаты имеют нейтральные
заглушки до заполнения. Новая проверка создаётся кнопкой «Новый результат».

Все данные и черновики хранятся только в React state. Перезагрузка страницы
восстанавливает mock-данные и удаляет изменения текущей сессии.

```sh
npm run build
npm run lint
npm test
```

UI-компоненты добавлены официальным CLI shadcn/ui. Настройка: `components.json`,
Tailwind Vite plugin, алиас `@/`. Модели: `src/types.ts`; стартовые данные:
`src/data/mockData.ts`.
